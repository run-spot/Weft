# Weft Gradle Build Logic

This included build provides the `weft.kmp-library` and `weft.maven-publish` convention plugins used by the capability libraries and BOM. Version pins live in `../gradle/libs.versions.toml`; shared Android defaults and the publication group live in the repository `gradle.properties`. Maven artifact IDs use the `weft-` prefix.

See [AGENTS.md](AGENTS.md) for the current milestone and change rules.
